# Закреплённые копии заготовки ebt/ для TypeScript (ebt-gate --scaffold ts).
#
# Формат строки: <оригинал>  <путь в клоне продукта>.
#   * kit:<путь> — файл из ресурсов установленной поставки (ebt-gate --installation,
#     поле resources); так закрепляются SDK и помощники наблюдения;
#   * путь без kit: — файл рядом с ebt/ (например, obs/session.ts);
#   * абсолютный путь — внешний файл.
# Копия должна совпадать с оригиналом байт в байт. Отличие или отсутствие файла —
# причина pinned_drift и FAIL гейта, а не предупреждение.
#
# Путь назначения ниже — пример: поставьте тот, куда проект кладёт SDK.
kit:lib/ebt/ebt.ts  src/lib/ebt/ebt.ts

# Помощники уровня наблюдения (D29) закрепляются так же: файл в ebt/obs/ копируется
# в продукт без изменений и сверяется гейтом.
# obs/session.ts  src/test/ebt/session.ts
